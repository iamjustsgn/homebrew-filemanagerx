# homebrew-filemanagerx

Official Homebrew Tap for **FileManagerX** macOS application.

## Installation

```bash
# 1. Tap this repository
brew tap iamjustsgn/filemanagerx

# 2. Install the cask
brew install --cask filemanagerx
```

Or install directly via fully qualified cask name:

```bash
brew install --cask iamjustsgn/filemanagerx/filemanagerx
```
